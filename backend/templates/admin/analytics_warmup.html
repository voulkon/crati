Analytics Cache Warmup

Pre-populate Redis cache for heavy analytics views (explore_orgs, da_top_pairs) across daily/weekly/monthly/yearly windows.

How it works:
  • Runs the same warm_analytics_cache Celery task used by the post-import chain.
  • Computes fresh data and writes it to Redis under the exact same cache keys the views look up.
  • When the scheduled run fires later (2 AM / post-import), it will naturally overwrite any values set here — the scheduled run is always the final source of truth.
  • You can also run this from the CLI: python manage.py warm_analytics_cache --async
