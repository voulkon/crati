💡 Understanding Storage Metrics

  • Total Size: Includes table data + TOAST storage + all indexes
  • Table Data: Just the main table data (heap)
  • External Size: TOAST storage (large text/binary) + indexes
  • Dead Rows: Deleted/updated rows waiting for VACUUM cleanup
  • Bloat %: Percentage of dead rows relative to live rows
  • TOAST: PostgreSQL's system for storing large column values (text, bytea, etc.) separately from the main table
  • Index Scans: Number of times an index has been used in queries (0 = unused index)

ℹ️ Quick VACUUM (Recommended)

• Runs concurrently with normal operations
• Does NOT lock the table
• Marks dead space for reuse (doesn't shrink file)
• Updates query planner statistics
• Safe to run anytime

⚠️ VACUUM FULL (Use with caution!)

• LOCKS THE ENTIRE TABLE during operation
• Blocks ALL reads and writes
• Actually shrinks the physical file size
• Can take 10-30+ minutes on large tables
• Only use during maintenance windows!
