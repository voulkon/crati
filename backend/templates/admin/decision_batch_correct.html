What this does

  1. Finds all decisions whose computed total exceeds the threshold.
  2. Reads the actual document text for each decision — if a decision has no extracted text yet and “Read if missing” is checked, the document is downloaded and extracted first.
  3. Uses the cents-based detector to find monetary amounts in the text (numbers ending with ,00, ,50, etc. — the defining signal of money in Greek documents).
  4. For each DecisionAmountField row whose value is NOT found verbatim in the text but HAS a ×100 or ÷100 clone, stores the corrected value in verified_amount.
  5. All downstream consumers use COALESCE(verified_amount, amount) so corrected values automatically override the erroneous metadata everywhere — API filtering, pre-calc rankings, statistics.

⚠️ Tip: Use Dry Run first to preview what would be corrected before making changes.
