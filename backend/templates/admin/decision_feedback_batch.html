What this does

  1. Finds all decisions with corrected amounts that have not been reported yet.
  2. For each, POSTs to https://diavgeia.gov.gr/luminapi/api/feedback/new with documentId = the decision's ADA.
  3. Stores the returned reference number and the raw response on a DiavgeiaFeedbackReport row (one per decision — reported, reported_at, reference).
  4. Progress is tracked on a job row and visible on the job status page (auto-refreshes while running).

⚠️ Tip: Use Dry Run first to preview what would be sent without making any API calls.
