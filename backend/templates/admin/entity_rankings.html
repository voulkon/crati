Entity Rankings Computation

Pre-compute per-entity statistics (total_amount, decision_count, rank_by_amount, rank_by_frequency, etc.) across daily/weekly/monthly/yearly time windows.

How it works:
  • Runs the same compute_entity_rankings Celery task used by the post-import chain.
  • Computes statistics for every AFMEntity and stores them in AnalyticsSnapshotRun + EntityAnalyticsSnapshot models.
  • Results are used by analytics views for leaderboards and trends.
  • You can also run this from the CLI: python manage.py compute_entity_rankings --async
