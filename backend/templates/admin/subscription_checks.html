Subscription Notification Checks

Trigger a bulk check of all active notification subscriptions against yesterday's new decisions.

How it works:
  • Runs the same trigger_check_all_subscriptions Celery task used by the post-import chain.
  • Fans out to check_all_active_subscriptions, which checks each active daily/weekly subscription independently.
  • Each subscription that has new matching decisions will generate a notification for its owner.
  • You can also run this from the CLI: python manage.py trigger_subscription_checks --async
