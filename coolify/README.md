# Coolify Configuration Directory

This directory contains generated configuration files for Coolify deployments.

## Structure

```
coolify/
├── dns-records.ENVIRONMENT.json      # DNS records audit log
├── labels.ENVIRONMENT.yml            # Traefik/Caddy labels
├── deployment-guide.ENVIRONMENT.md   # Deployment instructions
└── archive/                          # Archived configurations
    └── ENVIRONMENT/
```

## Files

### `dns-records.ENVIRONMENT.json`
Audit log of all DNS records created in Cloudflare for an environment.
Used by cleanup script to remove records.

### `labels.ENVIRONMENT.yml`
Traefik/Caddy labels for routing and SSL configuration.
Reference when configuring services in Coolify UI.

### `deployment-guide.ENVIRONMENT.md`
Complete step-by-step deployment guide specific to the environment.
Includes:
- DNS verification steps
- Environment variable configuration
- Service domain setup
- Post-deployment tasks
- Troubleshooting

## Archive

When running `cleanup-environment.sh`, files are moved to `archive/` with timestamps.

## Usage

These files are generated by:
```bash
util_scripts/coolify-setup/setup-environment.sh ENVIRONMENT
```

And cleaned up by:
```bash
util_scripts/coolify-setup/cleanup-environment.sh ENVIRONMENT
```
