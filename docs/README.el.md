# Ευρετήριο Τεκμηρίωσης

🚧 **Η ελληνική τεκμηρίωση βρίσκεται υπό κατασκευή**

Καλώς ήρθατε στην τεκμηρίωση της πλατφόρμας Crati.Co! Αυτός ο οδηγός θα σας βοηθήσει να πλοηγηθείτε στην τεκμηρίωση και να βρείτε αυτό που χρειάζεστε.

## 📖 Πλήρης Τεκμηρίωση (Αγγλικά)

Η πλήρης τεκμηρίωση είναι διαθέσιμη στα αγγλικά:

- **[Αρχική Σελίδα](../../README.en.md)** - Επισκόπηση έργου και γρήγορη εκκίνηση
- **[Επισκόπηση Αρχιτεκτονικής](../en/ARCHITECTURE.md)** - Κατανόηση του σχεδιασμού του συστήματος
- **[Οδηγός Ανάπτυξης](../en/DEPLOYMENT.md)** - Εκτέλεση της πλατφόρμας
- **[Μεταβλητές Περιβάλλοντος](../en/ENVIRONMENT_VARIABLES.md)** - Αναφορά διαμόρφωσης
- **[Λεπτομέρειες Συστατικών](../en/components/)** - Τεχνικές λεπτομέρειες

## 🤝 Βοηθήστε στη Μετάφραση

Θα θέλαμε να μεταφράσουμε αυτήν την τεκμηρίωση στα ελληνικά! Εάν θέλετε να βοηθήσετε:

1. Ανοίξτε ένα issue στο GitHub
2. Επιλέξτε ένα έγγραφο για μετάφραση
3. Υποβάλετε ένα Pull Request με τη μετάφρασή σας

Δείτε το [CONTRIBUTING.md](../../CONTRIBUTING.md) για περισσότερες πληροφορίες.
