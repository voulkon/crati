# Προσθήκη Ελληνικής Τεκμηρίωσης

Αυτός ο φάκελος θα περιέχει την ελληνική τεκμηρίωση.

## Κατάσταση Μετάφρασης

Η ελληνική τεκμηρίωση βρίσκεται υπό ανάπτυξη. Δείτε την πλήρη τεκμηρίωση στα [Αγγλικά](../en/).

## Βοηθήστε στη Μετάφραση

Θα θέλαμε τη βοήθειά σας για τη μετάφραση της τεκμηρίωσης! Δείτε το [CONTRIBUTING.md](../../CONTRIBUTING.md) για περισσότερες πληροφορίες.

### Προτεραιότητες Μετάφρασης

1. **Υψηλή** - README και Quick Start
2. **Μεσαία** - Οδηγός Εγκατάστασης
3. **Χαμηλή** - Τεχνική τεκμηρίωση (οι περισσότεροι developers είναι comfortable με αγγλικά)
